# KMate GKS RAG

Retrieval backend for KMate's GKS Scholarship Assistant (`/gks`).

Two knowledge layers are retrieved and ranked **separately**, and never merged:

* **Official** — chunks parsed from the GKS-U and GKS-G application guideline
  PDFs. Hard-filtered by program: a GKS-U question can never be answered with
  GKS-G rules, or vice versa.
* **Community** — 6,062 clustered Q&A threads from GKS applicant WhatsApp
  groups. Program-tagged and program-*preferred* rather than filtered, since
  most groups cover both tracks and general experience travels between them.

Community answers are never presented as official rules, and when the selected
guideline doesn't address what was asked, the response says so instead of
letting topical similarity imply a requirement.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS/Linux

pip install -r requirements.txt
python -m app.rebuild
uvicorn app.main:app --reload --port 8000
```

Open http://localhost:8000/docs

## Commands

| Command | What it does |
| --- | --- |
| `python -m app.rebuild` | Everything below, in order. The one command to rebuild from committed sources. |
| `python -m app.check_sources` | Verify the source PDFs still match `data/official/sources.json`. |
| `python -m app.check_sources --remote` | Also re-fetch `origin_url` and report upstream drift. Read-only. |
| `python -m app.ingest_official_pdfs` | Source PDFs → `data/official/official_knowledge.jsonl`. |
| `python -m app.tag_community_programs` | Raw chat export → `data/community/community_knowledge.jsonl` (adds UG/G tags). |
| `python -m app.build_index` | Both knowledge files → `index/`. |
| `python -m tests.test_retrieval` | Retrieval guarantees (program isolation, thresholds, API validation). |
| `python -m tests.run_evaluation` | 47-question evaluation set → `tests/evaluation_results.json`. |

## Asking

```bash
curl -X POST http://localhost:8000/ask \
  -H "Content-Type: application/json" \
  -d '{"program":"UG","question":"Do I need to apostille my transcript?"}'
```

`program` is required and must be `"UG"` or `"G"`. Without `OPENAI_API_KEY`,
`/ask` returns the retrieved evidence in readable form (`mode:
"retrieval_only"`); with a key, it generates an answer from that same evidence.
The key is only ever read by this service — never sent to a browser.

## Data

| Path | Committed? | Notes |
| --- | --- | --- |
| `public/official-guidelines/*.pdf` (repo root) | yes | Source guideline PDFs, hash-pinned in the manifest. |
| `data/official/sources.json` | yes | Provenance: URL, program, cycle, retrieval date, sha256. |
| `data/community/rag_ready_community.jsonl` | yes | Raw chat export. Never modified by any build step. |
| `data/official/official_knowledge.jsonl` | no | Generated by ingestion. |
| `data/community/community_knowledge.jsonl` | no | Generated by tagging. |
| `index/` | no | Generated by `build_index`. |

Generated files are gitignored and rebuilt deterministically — no build step
touches the network, so the output depends only on what's in the repository.

Adding a new cycle's guideline, or deploying this service, is described in
[DEPLOYMENT.md](DEPLOYMENT.md).
